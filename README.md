# Project UAS Data Mahasiswa (Python OOP)

## Deskripsi
Program ini dibuat untuk mengelola data mahasiswa dengan cara menginput
Nama, NIM, Nilai Tugas, Nilai UTS, dan Nilai UAS.  
Program kemudian menghitung **nilai akhir mahasiswa** berdasarkan bobot nilai.

Program dikembangkan menggunakan **bahasa Python** dengan konsep
**Object Oriented Programming (OOP)** dan **modular programming**.

---

## Konsep Program
Program menerapkan konsep OOP dengan pembagian tugas sebagai berikut:
- **Model**: menyimpan data mahasiswa dan menghitung nilai akhir.
- **Controller**: memproses data dari input dan mengatur alur program.
- **View**: menampilkan menu, menerima input, dan menampilkan output.

Program dijalankan melalui file **main.py** sebagai entry point utama.

---

## Fitur Program
- Input data mahasiswa
- Validasi input agar nilai berupa angka
- Perhitungan nilai akhir
- Menampilkan data dan hasil perhitungan ke terminal
